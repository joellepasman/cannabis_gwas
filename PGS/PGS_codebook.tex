\section{Prepare data}\label{prepare-data}}

This code shows how polygenic risk scores were created to capture
genetic risk for cannabis use to predict a set of outcomes in the STAGE
dataset from the Swedish Twin Register. The genotype data are located at
a different cluster space (Uppmax Bianca) than the phenotypic data and
were linked by STR.

were done on the Uppmax HPC. We approached (Nagelkerke's) R2 difference
between models with an without the PGSs using bootstrapping, using bca
where possible. All continuous predictors and outcomes were
standardised. For binary outcomes, logistic regression was used.
